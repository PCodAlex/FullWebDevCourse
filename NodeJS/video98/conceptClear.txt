# 🔹 1. Importing Module

```js
const fs = require('fs');
```

### What is this?

* `require('fs')` → imports the **File System module**
* `fs` → built-in Node.js module
* It allows you to:

  * Read files
  * Write files
  * Create files
  * Delete files

So here → you are using it to manage `tasks.json`.

```js
const filePath = "./tasks.json";
```

* `"./"` → current folder

* So this means:
  👉 `tasks.json` is in same directory as this JS file

# 🔹 3. loadTask() Function

```js
const loadTask = () => {
    try {
       const dataBuffer = fs.readFileSync(filePath);
       const dataJSON = dataBuffer.toString();
       return JSON.parse(dataJSON);
    } catch (error) {
        return [];
    }
}
```

### Step-by-Step Breakdown

---

### ✅ `fs.readFileSync(filePath)`

* Reads file synchronously
* Returns a **Buffer**, NOT a string

Example Buffer:

```
<Buffer 5b 7b 22 74 61 73 6b 22 ... >
```

---

### ✅ `.toString()`

```js
const dataJSON = dataBuffer.toString();
```

Converts Buffer → String

Example:

```
'[{"task":"Study Java"}]'
```

---

### ✅ `JSON.parse()`

```js
return JSON.parse(dataJSON);
```

Converts string → JavaScript Array/Object

Result:

```js
[
   { task: "Study Java" }
]
```

---

### ✅ `try...catch`

Why?

If file does not exist:

* `readFileSync()` will throw error
* catch block runs
* returns empty array `[]`

So first time app runs → no crash.

---

# 🔹 4. savaTask() Function

```js
const savaTask = (tasks) => {
    const dataJSON = JSON.stringify(tasks);
    fs.writeFileSync(filePath, dataJSON);
}
```

### What happens here?

---

### ✅ `JSON.stringify(tasks)`

Converts JavaScript array → JSON string

Example:

```js
[
  { task: "Study Java" }
]
```

becomes:

```
'[{"task":"Study Java"}]'
```

---

### ✅ `fs.writeFileSync()`

Writes that string into `tasks.json`.

If file doesn’t exist → it creates it.

---

# 🔹 5. addTask()

```js
const addTask = (task) => {
    const tasks = loadTask();
    tasks.push({ task });
    savaTask(tasks);
    console.log("task added :", task);
}
```

### Step-by-step

1. Load old tasks
2. Add new task
3. Save again
4. Print message

---

### Important Line

```js
tasks.push({ task });
```

This is shorthand for:

```js
tasks.push({ task: task });
```

So if user types:

```
node app.js add "Study"
```

Stored like:

```json
[
  { "task": "Study" }
]
```

---

# 🔹 6. listTask()

```js
const listTask = () => {
    const tasks = loadTask();
    tasks.forEach((task,index) => {
        console.log(`${index+1} - ${task.task}`);
    });
}
```

### Explanation

* `forEach()` loops through array
* `task` → object
* `index` → position

If array:

```js
[
  { task: "Study" },
  { task: "Gym" }
]
```

Output:

```
1 - Study
2 - Gym
```

---

# 🔹 7. removeTask()

```js
const removeTask = (index) => {
    const tasks = loadTask();

    if (index > 0 && index <= tasks.length) {
        const removed = tasks.splice(index - 1, 1);
        savaTask(tasks);
        console.log("Task removed:", removed[0].task);
    } else {
        console.log("Invalid task number");
    }
};
```

---

### Important Concept

User sees list starting from **1**

But array index starts from **0**

So:

```js
index - 1
```

---

### Example

If user runs:

```
node app.js remove 2
```

Internally:

```
splice(1,1)
```

Removes 2nd element.

# 🔹 8. process.argv

```js
const command = process.argv[2];
```

### What is process.argv?

If you run:

```js
  'add',
  'Study'

```

So:

| Index | Value  |
| ----- | ------ |
| 0     | node   |
| 1     | app.js |
| 2     | add    |
| 3     | Study  |

# 🔹 9. Command Control (Decision Making)

```js
if(command==="add"){
    addTask(argument);
}else if(command==="list"){
    listTask();
}else if(command==="remove"){
    removeTask(parseInt(argument));
}else{
    console.log('command not found');
}
```

This is your command router.

---

### parseInt(argument)

Because argument comes as string:

```
"2"
```

You convert it to:

```
2
```

So math operations work correctly.
