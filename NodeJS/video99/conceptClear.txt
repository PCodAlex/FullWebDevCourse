# 🔹 5️⃣ Get File Extension

```js
const extName = String(path.extname(filePath)).toLowerCase();
```

If file is:

* `index.html` → `.html`
* `style.css` → `.css`
* `app.js` → `.js`

---

# 🔹 6️⃣ MIME Types

```js
const mimeTypes = {
    '.html':'text/html',
    '.css':'text/css',
    '.js':'text/javascript',
    '.png':'text/png'
};
```

### What is MIME type?

It tells browser **what kind of file it is**.

Example:

| File | MIME Type       |
| ---- | --------------- |
| html | text/html       |
| css  | text/css        |
| js   | text/javascript |

---

# 🔹 7️⃣ Content Type Selection

```js
const contentType = mimeTypes[extName] || 'application/octet-stream';
```

If extension exists → use correct type
If not → use default type
