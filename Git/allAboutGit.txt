🧨 Merge Conflict (Important interview topic)
When conflict happens?

When same file same line edited in both branches.

Example:

main branch:     Hello Java
feature branch:  Hello Python

Git cannot decide → conflict

⚠️ After conflict you will see
CONFLICT (content): Merge conflict in file.txt

File will look like:

<<<<<<< HEAD
Hello Java
=======
Hello Python
>>>>>>> feature
🛠 How to solve conflict
1️⃣ Open file and edit manually

Choose correct code:

Hello Java & Python

Remove:

<<<<<<< ======= >>>>>>>
2️⃣ Add again
git add fileName
3️⃣ Commit merge
git commit -m "conflict resolved"

🟣  git diff (very important)
👉 Purpose:

Shows changes between files/commits

git diff

Shows changes not staged yet.

Symbols in git diff

Example:

- → removed line

+ → added line

white line → unchanged

@@ -1,4 +1,4 @@

Shows line numbers changed.

Types of git diff commands
1️⃣ See unstaged changes
git diff
2️⃣ See staged changes
git diff --staged
3️⃣ Compare commits
git diff commit1 commit2
4️⃣ Compare branches
git diff main feature
5️⃣ Check one file diff
git diff fileName

🟣  Git Stash (very important 🔥)
👉 Stash = temporarily save work without commit

Suppose coding not finished but need branch switch.

git stash

Git saves work and makes folder clean.

Commands of stash
1️⃣ Save stash
git stash
2️⃣ See stash list
git stash list

Output:

stash@{0}
stash@{1}
3️⃣ Apply stash (keep stash also)
git stash apply
4️⃣ Pop stash (apply + delete)
git stash pop
5️⃣ Apply specific stash
git stash apply stash@{1}
6️⃣ Delete stash
git stash drop stash@{0}
7️⃣ Clear all stash
git stash clear

******************** git rebase ********************

🟣 1️⃣ What is Git Rebase?

👉 Rebase = move your branch on top of another branch

Instead of creating a merge commit, it rewrites history and makes it clean & linear.

🟣 2️⃣ Why We Use Rebase?

✅ Clean commit history
✅ No unnecessary merge commits
✅ Makes project history straight line
✅ Preferred in professional workflow

🟣 3️⃣ How Rebase Works (GitLens Graph Style)
🧠 Suppose this situation:
main:     A --- B --- C
                   \
feature:             D --- E

Now main got new commit C

If you run:

git checkout feature
git rebase main
👉 What Git does internally:

Remove commits D, E

Move feature to C

Re-apply D, E on top

🔥 After Rebase (GitLens graph view)
main:     A --- B --- C
                          \
feature:                    D' --- E'

⚠️ Notice:
D and E become D' and E'
(New commit IDs created)

👉 No merge commit
👉 Clean history

🟣 4️⃣ Types of Rebase
1️⃣ Normal Rebase
git rebase main
2️⃣ Interactive Rebase (🔥 very powerful)
git rebase -i HEAD~3

Used to:

Edit commit message

Squash commits

Delete commits

Reorder commits

You will see:

pick 1234 commit1
pick 5678 commit2

You can change:

pick

squash

reword

drop

3️⃣ Rebase Onto

Advanced:

git rebase --onto branchA branchB

🟣 5️⃣ Why Rebase Not Recommended on main/master?

⚠️ Because rebase rewrites history

If main is shared on GitHub:

Rewriting history =

Other developers will face problems

Push will require --force

Can break team workflow

👉 Rule:

✔️ Rebase on your feature branch
❌ Don’t rebase shared main branch

Professional rule:

Feature branch → rebase on main
Main branch → use merge

🟣 6️⃣ Rebase Conflict

Conflict happens when:

Same file same line edited in both branches.

During rebase, Git stops and shows:

CONFLICT (content): Merge conflict in file.txt

File will show:

<<<<<<< HEAD
old code
=======
new code
>>>>>>> commitID

🟣 7️⃣ How to Fix Rebase Conflict
Step 1: Resolve manually

Edit file

Step 2:
git add fileName
Step 3:
git rebase --continue

🟣 8️⃣ What is --continue ?
git rebase --continue

👉 After resolving conflict
👉 Tells Git: "Continue applying next commit"

🟣 9️⃣ What is --abort ?
git rebase --abort

👉 Cancels rebase
👉 Returns branch to original state

Very useful if too many conflicts 😅

🟣 10️⃣ Merge vs Rebase (Quick Difference)
Merge	Rebase
Creates merge commit	No merge commit
Keeps history true	Rewrites history
Safe for shared branch	Risky on shared branch
Graph looks complex	Graph looks clean
